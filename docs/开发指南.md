## 一、环境与启动

```bash
npm install      # 首次会下载 Electron 二进制
npm run gen-icon # 生成图标（仓库已内置产物，可跳过）
npm start        # 启动
```

- 需要 **Node.js ≥ 18**、**Windows 10/11**。
- `better-sqlite3` v13 已迁移到 **N-API**，内置各平台预编译二进制，**无需** electron-rebuild，
  跨 Node / Electron 版本通用，也不依赖本机 Visual Studio 构建工具。

### 在 Electron 宿主里启动

若在自带 `ELECTRON_RUN_AS_NODE=1` 的环境（IDE 内置终端、部分 Agent 宿主）里运行，
Electron 会以 Node 兼容模式启动、`require('electron')` 失效，看起来像「启动即退出」。先清掉这个变量：

```bash
# Linux / macOS / Git Bash
env -u ELECTRON_RUN_AS_NODE npm start

# Windows PowerShell
$env:ELECTRON_RUN_AS_NODE=$null; npm start
```

普通终端启动不受影响。

## 三、依赖策略（体积硬约束）

前端第三方库（`markdown-it` / `highlight.js` / `mermaid` / `easymde` / `flatpickr` / `tom-select` /
`prettier` / `diff` / `jsonpath-plus` / `xml-formatter` / `sql-formatter` / `@alenaksu/json-viewer`）
**一律登记在 `devDependencies`**，构建期用 esbuild 打进 `renderer/vendor/`，把产物随仓库提交。

- 运行时不联网、也不读 `node_modules`；升级时把新产物覆盖到对应目录，并同步 `package.json` 版本号。
- `dependencies` 里**只留 `better-sqlite3`**。这条是硬约束：任何前端库误放进 `dependencies`，
  electron-builder 会把整棵 production `node_modules` 打进 `app.asar`，
  安装包从 30MB 级直接涨到 200MB 级。

## 四、验证

```bash
npm run test:db   # 数据层 + 报告生成 + 语音转写通道冒烟（纯 Node，不依赖 Electron、不入网）
npm run smoke     # 端到端冒烟（Electron 启动后自动退出，输出 SMOKE_OK）
```

- **冒烟测试使用独立的临时数据目录**（`os.tmpdir()/todo-smoke-profile`，每次启动前清空）：
  既保证每轮从干净状态开始（否则上一轮残留的「冒烟分组」会让下一轮撞上重名报错），
  也不污染真实数据。失败时打印「未通过项 · 分组：字段=值」，不必逐个核对几十个断言。
- UI 交互一律用**轮询等待**代替固定 `sleep`，规避冷启动偶发超时。
- 跑 `npm run smoke` 建议把超时放宽（约 3 分钟），并在 PowerShell 里先清 `ELECTRON_RUN_AS_NODE`。

### 定向验证 UI（调试端口）

需要确认某个交互时，带调试端口启动，用脚本连上去断言 / 截图：

```bash
# 后台启动
./node_modules/electron/dist/electron.exe . --remote-debugging-port=9444

# 另开一个脚本连现有窗口（自己 spawn 会被宿主回收）
curl http://127.0.0.1:9444/json/list
```

几条经验：

- WebSocket 会吊住 Node 进程，脚本结尾要 `process.exit(0)`。
- 后台节流会让断言超时：启动时加
  `--disable-background-timer-throttling --disable-renderer-backgrounding --disable-backgrounding-occluded-windows`。
- 合成按键进不到原生加速键（菜单快捷键只能在主进程侧探针验证）；
  `Runtime.evaluate` 里对动态 `import()` 求值会挂住，改成「发出去 + 轮询结果」。
- 断言要限定作用域：`.nt-empty` 这类选择器会同时命中侧栏标签。

## 五、代码约定（踩过的坑）

- **`#view` 是共享容器**：`renderTasks()` 整块重写它。非任务视图重新进入时要检测骨架是否还在再重建；
  局部刷新优先只换局部 DOM（整页重建会丢焦点 / 滚动，旧的自动保存器还会写已销毁的节点）。
- **会随骨架重建的控件走容器级委托**，常驻容器用 `WeakSet` 只绑一次；不要和逐个元素的直接绑定混用。
- **工具类 CSS 类名禁止复用**（例如高亮层是 `position:absolute; inset:0` 的 `<pre>`，
  借用一次就会变成覆盖全屏的原生控件）。
- 模块间互相跳转用 `await import()`，避免循环依赖。
- 弹窗统一走 `openPanelModal`：关闭前保存用 `onClose`，二选一的确认必须先 resolve 再 close。
- 渲染层不碰文件系统、不拿明文 Key，所有能力都从 `preload` 的 `contextBridge` 走。
