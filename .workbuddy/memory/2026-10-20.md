## Gitee 发行版（Release）——让用户直接下载安装包

### 官方限制（已查证 help.gitee.com）
- 发行版/仓库附件**单个 ≤100MB**（GVP 项目 200MB），每仓库总附件 ≤1GB。
- exe 直传不可行：安装版/便携版 exe 116MB 超限；NSIS 内部已 LZMA 压实，再压无收益（7z 后仍 241MB）。
- win-unpacked（401MB）→ zip(deflate) 166MB 仍超限 → 必须用 **7z(LZMA) + 瘦身**。

### 有效的瘦身组合（401MB → 94.9MB）
- 删 `locales/` 多余语言（只留 zh-CN/en-US/zh-TW，-47MB）
- 删 `dxcompiler.dll`（25MB，WebGPU shader 编译器，应用用不到；删后启动验证正常）
- 7z `-mx=9` 极限压缩：401→354MB（瘦身）→ **94.9MB**（`dist/release/TODO待办-1.0.0-win64.7z`）
- 大头：`TODO待办.exe` 236MB（Electron 44 主程序，压不动）、resources 32MB

### 工具链坑
- electron-builder 缓存自带 7za：`%LOCALAPPDATA%/electron-builder/Cache/7zip@1.0.0/7zip-win-x64-*/bin/7za.exe`
- 7za 是 Windows 程序，**不认 MSYS 的 /tmp 虚拟路径** → cd 进目录用相对路径操作
- 中断留下的半个 zip 再 `a` 会损坏（"Unexpected end of archive"）→ 先删干净重压

### 自动发布
- `scripts/release-gitee.js` + `npm run release`（GITEE_TOKEN 环境变量）：打 tag → 建 Release →
  传 `dist/release/*` 附件；已存在的 tag/Release/同名附件自动跳过；>100MB 拦截。
- Gitee API：创建 `POST /repos/{owner}/{repo}/releases`（JSON，access_token 在 body）；
  附件 `POST /repos/{owner}/{repo}/releases/{id}/attach_files`（multipart）。
