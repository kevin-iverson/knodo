## 代码块缩进修复 + mermaid 只留五类图表（v1.8.2）
- **缩进问题的真因**：CodeMirror 的 `defaultTab` 绑定 `insertTab`，按时塞进正文的是**真的 `\t`**；
  编辑器 tabSize=2（EasyMDE 默认）显示 2 格，预览的 `<pre>` 吃浏览器默认 `tab-size: 8` → 同一段代码
  预览里像「缩进多了一大截」。三处对齐成 2：`styles.css` 里给 `.md-code pre / .markdown-body pre /
  .editor-preview pre / .nt-md-fallback` 等统一 `tab-size: 2`；EasyMDE 显式 `tabSize: 2`；
  `notes.js` 里 `cm.addKeyMap({ Tab: ... insertSoftTab })` 让 Tab 插入空格（选中多行时 indentSelection）。
  验证：CDP 里 `cm.state.keyMaps` 能看到 `Tab`，`execCommand('insertSoftTab')` 得到 `"  "`；
  截图量到 Tab 宽度 ≈ 2 个字符。
- **mermaid 裁剪**：`scripts/build-tools.js` 新增 `mermaidStubPlugin()`，从 `mermaid.core.mjs` 解析
  `var idN = "..."` + 紧随的 `import("./chunks/mermaid.core/xxx.mjs")` 得到 detector→模块映射，
  把不在 keep 列表（flowchart-v2 / sequence / classDiagram / gantt / pie）里的 31 个图表模块换成空桩；
  再额外置空 `cose-bilkent-*.mjs`。**elkjs 绝对不能裁**（flowchart/class 的默认布局就是它，裁掉图会叠成一团，
  实测 SVG 体积腰斩）。5.0MB → 3.6MB。
- **空桩必须导出 `render`**：布局 loader 走的是 `layoutRenderer.render(...)`，桩里只有 `{diagram}` 时
  会抛 `i.render is not a function`，整张图废掉（踩过一次）。
- 渲染层加了同名单（`MERMAID_TYPES` + `detectMermaidType()`，跳过 frontmatter/`%%` 注释/空行），
  不支持的图在**加载库之前**就拦下并提示，不白等一次 3.6MB 的 import。
- 验证方式：CDP 起真应用，在页面里造一块 host 渲染 5 类图 + 1 个 kanban，断言
  `.md-mermaid.is-ok === 5`、错误文案只有一条「不支持的图表类型」、`getComputedStyle(pre).tabSize === '2'`；
  `dist/win-unpacked/resources/app.asar` 也用开发版 electron 直接加载过一遍（打包后 exe 不收命令行参数）。
