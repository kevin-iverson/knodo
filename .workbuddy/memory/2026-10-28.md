## 2026-10-28 笔记视图三项优化（全屏 / Mermaid 放大 / 导出入口）

- 全屏预览·编辑：`notes.js` 新增 `applyFullscreen/toggleFullscreen/exitFullscreen`，给 `.nt-dp` 加 `.is-fs`（`position:fixed; inset:0; z-index:320`）；按钮 `data-nt-act="fs-toggle"` 在 detailHtml 头部（右栏与弹窗共用），状态记 localStorage `nt-fullscreen`，Esc 在 document 捕获阶段退出（查找条/色板开着时让位）。预览态 1080px 阅读宽度居中，编辑/分栏占满。关闭面板 / 删除后 / 弹窗 onClose / `disposeNotes` 都要 `exitFullscreen()`，否则 Esc 监听器会一直挂在 document 上。
