# 2026-10-25

## 品牌重塑：TODO 待办 → Knodo（Knowledge + Todo）

### 用户决策（问过才动手的）
1. **只改对外名称**：`package.json` 的 `name`（`todo-desktop`）与 `build.appId` 保持不变。
   理由：Electron 用 `name` 决定用户数据目录。实证 —— 真实安装版的数据就在
   `%APPDATA%\todo-desktop`，而历史 productName 是「TODO待办」，那里**并没有** `TODO待办` 目录，
   说明数据目录只认 `name`，改 `productName` 不会动它。
2. **Logo 走 K+O 融合**：K 的竖线做清单竖条，O 做知识回路圆环，圆环上 3 个节点。

### 标识设计（写在 scripts/gen-icon.js 头部，改图形前先看那段注释）
- 圆角方块底 + 对角线渐变（#2E5BFF → #2450E8 → #16C8E8）。
- 圆环（O）= 知识回路；竖条（K 的竖线）= 清单勾选竖条，上下两端顶到圆环内缘成为一条弦；
  两条斜臂从竖条中点（拐点）射出，各经一条细连线连到圆环上的节点；第三个节点在圆环正右。
- **三档几何**（`geometry(mode)`，`modeFor(size)` 自动选）：
  `full`(≥48，含细连线) / `simple`(24~47，加粗去连线) / `tiny`(16，去节点 + 竖条右移)。
  16px 是踩出来的：竖条贴着圆环左弧会糊成一条白带，必须拉开；节点在 16px 也只会变成噪声。

### 挨过的三个坑
1. 第一版竖条太短且悬空 → 读不成 K；加一条水平细连线 → 变成「星形/扇子」。
   解决：删掉水平线，竖条加长顶到内缘，细连线**必须与斜臂共线**（否则是横着浮空的一段）。
2. 竖条与圆环左弧过近会挤出一条细缝（看着像渲染瑕疵）；把间距拉开后才干净。
3. 校验 ICO 时把 IHDR 的 chunk 长度当成了宽度（PNG 是 8 签名 + 4 长度 + 4 类型，数据在 +16 处）。
