# 快速语音录入任务 · 实现方案

> 状态：已上线（v2.9.0）
> 入口：`Ctrl+Alt+R`（全局，可改）→ 再按一次停止 → 确认卡 → 勾选后建任务
> 代码：`main/voice-task.js`（ASR + 提取 + 落库）、`renderer/js/voice-task.js`（录音内核 + 确认卡）、
> `renderer/css/voice.css`；验收 `npm run verify:voice`

## 一、它要解决的是「打字这一步太贵」

开车、做饭、手里有活的时候想起一件事，打开应用 → 找清单 → 敲字，这一串动作足够让人放弃记录。
所以这条链路只保留两个动作：**按一下说，再按一下看结果**。

不做「流式语音输入框」：边说话边把字打进输入框，用户还要自己断句、自己起标题、自己挑清单，
等于把成本转移到别处。这里直接给**成品的待办草稿**，用户只做减法（勾掉不想要的）。

## 二、三条不变量（改代码前先读）

1. **音频识别后即删。** 录音只经过「渲染层内存 → IPC base64 → 系统临时目录」，ASR 完成立刻 `unlink`。
   不进 `recordings/`、不进附件系统、不进备份包。需要留声音的场合是「🎙 录音 / 🖥 录屏」那条链路，
   两者刻意不复用。
2. **识别与落库分离。** `submit()` 只做 ASR + AI 提取，返回草稿，一个字节都不写库；`commit()` 只吃用户
   勾完的数组。中间那段是「用户可能全不选」的地带，不能有副作用 —— 否则每按一次快捷键都会在库里留下垃圾。
3. **`main/voice-task.js` 不 require `ipc.js`**（会成环）。配置读取在该模块内自己实现，
   settings 键与 `ipc.js#getAsrConfig / getAiConfig` 保持同一套；渲染层拿到的是信封，
   错误码靠 `__code` 还原（`contextBridge` 复制 `Error` 只保留 message/stack，`err.code` 会丢）。

## 三、状态机与接口

| 阶段 | 位置 | 说明 |
|---|---|---|
| 开麦 | 渲染层 `MediaRecorder` | 主进程只把窗口唤起来并推 `ui:voice-toggle`，**不持录音状态** |
| 停录 | 渲染层 | 只在内存里攒 webm，停录后一次性 base64 过 IPC |
| 识别 | 主进程 `submit()` | 写临时文件 → ASR 转写 → 删文件 → AI 抽待办 → 返回草稿 |
| 确认 | 渲染层卡片 | 与截图建任务同一套 `.shot-*` 骨架，卡顶是麦克风块 |
| 落库 | 主进程 `commit()` | 只建勾选的条目，`planEnd = 今天`，描述里回带转写原文 |

IPC：`voice:status` / `voice:submit` / `voice:commit`，preload 一律走 `envelope()`
（`api.voiceTask.*`），卡片侧 `voiceApi()` 把 `{ok:false,code}` 还原成带 `code` 的异常 ——
`NO_ASR_KEY` / `NO_API_KEY` 走「去配置」，其他走「重试」。

快捷键只有一张卡、一条录音：卡片打开时再按快捷键直接忽略；录音中再按是「停止」而不是叠第二个遮罩。

## 四、几个具体取值

- **20MB 上限**（`MAX_AUDIO_BYTES`）：webm/opus 约十几分钟，再长就该用会议录制。
- **转写截 12000 字**（`MAX_TRANSCRIPT_CHARS`）送模型，避免超上下文；回给卡片的是完整原文。
- **描述里只回带 2000 字**（`MAX_NOTE_TRANSCRIPT`）：够核对「当时说的是这句」，不至于把任务描述撑成一篇稿。
- **落库分组**：上一次手动选过的分组（`ui.lastAddGroupId`）→ 最近用过的分组 → 第一个分组；
  一条分组都没有时直接报 `NO_GROUP`，不让任务落进「无分组」黑箱。

## 五、踩过的坑

- **骨架屏是中间态，测试不能靠抢。** mock 秒回时卡片会在下一个 CDP 往返之前就切到结果页，
  「先显示骨架」永远假红。`verify:voice` 的 mock ASR 故意延迟 300ms（`ASR_DELAY_MS`）。
- **全局热键是整机唯一资源。** 本机另开着一份 Knodo 时，这一份实例的 16 个热键全部注册失败 ——
  验收脚本按「一个都没注册上 → 判环境不可测并跳过；别的键注册上、唯独它没有 → 真失败」两分。
- **音频不进附件，所以没有 `attachments` 行、也没有 `todo-media://` 链接**；卡片里也刻意不显示波形 / 播放器，
  否则用户会以为文件被留下了。
