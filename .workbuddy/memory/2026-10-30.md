## 笔记预览态搜索（Ctrl+F 在只读预览里也能查）

- `renderer/js/note-find.js` 从「只服务 CodeMirror」扩成双后端：
  - `backend:'cm'`（编辑 / 分栏）→ 原来的 `getSearchCursor` + `markText`，一行为未改；
  - `backend:'dom'`（预览）→ TreeWalker 遍历 `#nt-preview` 文本节点，`Range.surroundContents` 包
    `<mark class="nt-find-hit">`，当前项 `.is-current`；**倒序包裹**保证同节点内偏移不错位；跨节点命中放弃
    （不去拆 `<strong>/<code>` 的渲染结构）；跳过 svg/style/script。
  - 两种后端共用同一根浮条、同一套计数 `N/M`、↑↓ 翻（回车 / Shift+回车 / F3）、Aa 区分大小写、✕ / Esc 关闭；
    预览态不渲染替换行（`buildBar({replace})`），`doReplaceOne/All` 也加了 backend 守卫。
- `notes.js`：`findTarget()` 按 `mode` 给 backend；`openNoteFind()` 预览态不再 `switchMode('split')`
  （Ctrl+H 仍切分栏，因为替换要写源码）；`switchMode()` 用 `findQuery()` 把查询词带到新后端；
  `refreshPreview()` 末尾 `refreshFind()` 重算命中标记。
- 交互补丁（都是「预览里没有可聚焦控件」引出的连锁问题）：
  - `.nt-dp-scroll` 加 `tabindex="-1"` + `focusPreviewOnPress`（mousedown 委托，右栏与弹窗各一份）——
    否则点过正文后 `activeElement` 在 body，`closest('.nt-dp')` 判定落空，Ctrl+F 完全没反应；
  - 预览选区可预填（`selectionInPreview`，只取首行、≤80 字）；
  - `input` 委托对 `.nt-find` early-return：查找框打字不再把笔记标成「未保存」；
  - `modal.js` 的 Esc 看到 `[data-esc-stop]` 让位 → 弹窗里 Esc 先关搜索条、再关弹窗。
- 样式：`renderer/css/styles.css` 加 `.nt-find-hit / .is-current`（与 `.cm-find-hit` 同配色，含深色主题）、
  `.nt-dp-scroll:focus{outline:none}`。
- 验证（CDP 连 9444 的开发实例，全新 `--user-data-dir`）：预览 Ctrl+F 计数 1/6、逐字输入增量命中、
  回车/Shift+回车跳转并滚动、Aa 5/6、无结果标红、切分栏换后端保留查询词（CM 内 6 处标记）、切回预览恢复
  DOM 标记、Esc 关闭后 `#nt-preview` innerHTML **与搜索前逐字节一致**、富文本命中（strong/code/a）、
  全屏搜索、弹窗内搜索 + Esc 只关浮条、替换全部 4 处；`npm run smoke` → `SMOKE_OK`。
