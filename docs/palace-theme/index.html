太和殿 · 脊兽

把太和殿檐角的十只走兽、一位骑凤仙人，连同宫门前的两只石狮，请到界面边沿站成一队。鼠标经过，它会告诉你自己从哪里来、又护着什么。

屋脊兽原本只是钉住瓦片的铁钉帽，后来成了等级的语言：走兽越多，殿宇越尊。太和殿是全国唯一用满十只的建筑，多出来的那一位，叫「行什」。

形象次序按《大清会典》与故宫博物院公布：骑凤仙人领队，其后龙、凤、狮子、天马、海马、狻猊、押鱼、獬豸、斗牛、行什。

十三个形象 CHARACTER SHEET

统一比例：头大身小、端坐姿态；一只金铃、一道项圈、一撮腮红。各自的角、翼、尾、鳍，负责在 48 像素里也能认出是谁。

放回界面里 IN THE INTERFACE

以待办应用为例：边沿成为一道檐口，脊兽依次站在琉璃瓦上，介绍卡在鼠标经过时浮起；明暗两套配色都留了位置。

色与形 TOKENS

取宫墙、琉璃、青绿彩画与汉白玉。朱红压场，赤金点睛，其余颜色都退半步。

形制与用法

  • 脊线：一道 2px 赤金，之上站兽，之下是琉璃瓦垄；石狮压两端，略大于走兽。
  • 介绍卡：悬停浮起，点击钉住；箭头始终指向被指的那一尊。
  • 印章：朱红底、金边，置于标题与卡片角落，是这套界面的落款。
  • 落地：十三个 SVG 直接可用；48–56px 为界面尺寸，120px 以上可作插画。
