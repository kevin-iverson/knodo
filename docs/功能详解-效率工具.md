# 功能详解 · 效率工具与数据

除了任务与笔记，Knodo 还带了一组「顺手就能用」的小工具、把数据送去别的产品的导出通道、
以及桌面级的集成（托盘、自启动、存储位置）。

> 相关文档：[数据库设计](数据库设计.md) · [打包与发布](打包与发布.md) · [常见问题](常见问题.md)

---

## 一、实用工具浮窗

入口：**顶部菜单栏 → 实用工具**。三个工具都是**非模态浮窗**：不挡主界面，可以边开着工具边操作任务；
同一种工具只保留一个实例，位置与大小记在本地，关掉再开还是原样。

| 工具 | 快捷键 | 说明 |
|---|---|---|
| **文本对比** | `Ctrl+Shift+D` | 并排 / 内联两种视图，行内 token 级高亮；可交换两侧、忽略空白 / 空行 / 大小写；带增删统计与「复制差异」，支持先各自格式化再比 |
| **JSON 查看器** | `Ctrl+Shift+J` | 左侧源码 + 右侧树形视图，键名 / 值搜索、一键展开层级、JSONPath 查询 |
| **实时薪资** | `Ctrl+Shift+S` | 按时薪折算「今日已获得 / 本月累计」，只显示金额不显示月薪 |

浮窗支持最小化（收起为标题条）、最大化、拖拽调整大小（双击手柄复位）。

### 实时薪资的计算口径

- 只算工作日（周一 ~ 周五），周末整段跳过；
- 只算「上班时间 ~ 下班时间」区间内的时长，早到 / 加班都不算钱；
- 今日 = 今天这段区间里已经过去的部分（上班前为 0，下班后封顶为全天工时）；
- 本月 = 本月 1 号到今天，同样的口径逐日累加；
- 时薪 = 月薪 ÷ **当月工作日数** ÷ 每日工时（不用固定的 21.75，这样整月全勤正好等于月薪）。

配置（月薪 + 上下班时间）存 `settings.tool.salary`，下次打开直接回填。

> 浏览器端的三方库（prettier / diff / json-viewer / sql-formatter / xml-formatter / jsonpath-plus）
> 在构建期由 `scripts/build-tools.js` 用 esbuild 打成 `renderer/vendor/tools/*.mjs`，按需 `import()`，
> 不拖慢主界面启动。

## 二、☁ 同步：导出到其它产品

菜单栏「File → 同步到腾讯文档 / ima…」把本地数据导出成第三方产品能直接吃下的格式。**导出是单向的**：
只生成文件，不改动本地数据。

### 任务导出

| 项 | 可选值 |
|---|---|
| 格式 | **CSV**（新建腾讯文档在线表格 → 导入数据即可）、**Markdown 表格** |
| 范围 | 未归档（进行中 + 已完成）/ 仅进行中 / 仅已完成 / 全部（含已归档） |
| 分组 | 全部分组，或按分组树选择 |
| 子任务 | 可选择是否包含 |

### 笔记导出

| 项 | 可选值 |
|---|---|
| 打包方式 | **每篇一个 `.md` 的压缩包（含图片）** —— 可批量上传到 ima 知识库；**合并成单个 Markdown** —— 适合整篇粘贴 |
| 目录 / 标签 | 按目录、按标签筛选 |
| 归档 | 可选择是否包含已归档笔记 |

笔记视图工具栏的「📤 导出」是同一套面板，只是只保留笔记一节。

## 三、数据备份：完整备份包 / 自动快照

主界面工具栏「📤 备份 / 📥 导入」，以及菜单 **File → 备份与恢复…**。

### 完整备份包（`.zip`）

- **导出**：一个 `.zip`，内含
  - `manifest.json`：版本、各表条数、附件与录音数量、导出时已丢失的文件清单；
  - `db.json`：分组、标签、任务、关联、笔记、会议、报告、检索历史、设置；
  - `attachments/`：任务与笔记的图片 / 附件**本体**；
  - `recordings/`：会议录音分片（只带被会议引用到的那些）。
- **导入**：`.zip` 与旧版 `.json` 都认。附件解到当前数据目录，录音的绝对路径按新机器重写。
- **缺失清单**：导入后若仍有附件找不到文件（例如用了不含附件的旧版 JSON 备份），
  会逐条列出是哪个任务 / 笔记的哪个文件，而不是静默显示破图。
- **不包含**：AI / 语音 API Key（安全），以及可重建的派生数据（知识库分块 / 索引）。
- 导入是**覆盖式**的（任务 / 分组 / 标签 / 笔记 / 会议记录），主题与 AI 配置保留。

### 自动快照（每日）

- 启动 5 分钟后首次，之后每 24 小时一份，写到 `<数据目录>/backups/knodo-YYYYMMDD.db`。
- 保留策略：最近 7 天每日 1 份 + 更早的每周 1 份（最多 4 周），总量上限 500MB。
- 备份前跑 `PRAGMA quick_check`：库本身已损坏时不拿它去覆盖历史备份。
- 菜单 **File → 备份与恢复…**：查看最近备份时间 / 占用、立即备份、打开备份目录、从备份恢复。
- 启动时主库打不开（被删 / 损坏 / 同步盘占位）会提示用最近一份快照恢复；
  坏掉的库文件改名成 `todo.db.broken-<时间>` 保留，必要时还能取回。
- **只保数据库**：附件与录音本体请用完整备份包搬到别的磁盘或网盘。

## 四、桌面集成

### 系统托盘

- 常驻托盘，图标菜单可显示 / 隐藏主窗口、快速添加任务、退出。
- **窗口「关闭」按钮默认最小化到托盘**；真正退出要走托盘菜单「退出」或应用内退出。

### 开机自启动

菜单 **File → 开机自启动**（勾选项）：登录系统后自动在后台启动，只驻留托盘、不弹主窗口。

- 勾选状态以**系统实际登记的启动项**为准（在「任务管理器 → 启动」里关掉也会同步反映）。
- 便携版与开发调试模式下不可用（无法登记稳定的启动路径），菜单项会置灰。

### 存储位置

菜单 **File → 存储位置** 可把数据目录换到任意位置（例如 D 盘）。

- 配置写在 `<用户数据目录>/config.json` 的 `dataDir` 字段，**下次启动生效**。
- 可勾选把现有数据（`todo.db` + `attachments`）复制到新目录。
- 目标目录里已经有 `todo.db` 时会拒绝覆盖，需要换一个空目录。
- 配置目录不可用（盘没插 / 被删 / 无写权限）时**自动回退默认目录并弹窗提示**，应用永远能启动。
- **录音文件（`recordings/`）不随迁移**：会议记录里存的是绝对路径，复制会造成两份数据。

## 五、全局快捷键与快速捕捉

两套键分工不同：上表那些 `Ctrl+Shift+*` 是**菜单加速键**，只在应用聚焦时有效；
**全局快捷键**在应用不在前台时也能触发，动作表只在 `main/shortcuts.js` 定义一份，共 12 个：

| 动作 | 默认键 |
|---|---|
| 唤起主窗口 | `Ctrl+Alt+B` |
| 显示 / 隐藏笔记（唤起并打开笔记弹窗） | `Ctrl+Shift+H` |
| 快速添加任务 | `Ctrl+Alt+N` |
| 快速捕捉 | `Ctrl+Alt+C` |
| 显示 / 隐藏桌面浮窗 | `Ctrl+Alt+D` |
| 唤起第 1~6 个桌面浮窗 | `Ctrl+Alt+1` ~ `Ctrl+Alt+6` |
| 实时薪资 | `Ctrl+Alt+L` |

- 桌面浮窗的显隐键用 `D`（Desktop）而不是原来的 `H`：`Ctrl+Alt+H` 与笔记键 `Ctrl+Shift+H`
  只差一个修饰键，实机上很容易按混，也会被键盘宏串到一起。
- 全部可在 **设置 → 快捷键** 里录制修改。换键是原子操作（先注册新键，成功才摘旧键）：
  新键被别的程序占用会当场说明并**保留原键**，不会出现「键换了、功能没了」。
- 系统保留组合（`Ctrl+Alt+Del`、`Win+L`、`Alt+Tab` 等）直接拒绝并给出原因。
- 同一个组合不会绑到两个动作上；改到原本属于另一个动作的键，那个动作会被置为「未设置」并提示。
  若两个动作的键真的撞了（旧配置 / 手动写入），**先注册的那个保留生效**，另一个放弃注册并写日志，
  不再互相摘键 —— 旧实现会两边轮流抢注，`list()` 里还都显示「已注册」，表现成「按 A 的键触发了 B」。
- 休眠 / 解锁后用 `globalShortcut.isRegistered()` 体检，丢了会自动补注册。

### 快速捕捉条

按 `Ctrl+Alt+C` 在**鼠标所在屏幕**顶部弹出一条 520×52 的输入框（距顶 96px）：

- 回车保存并**保持打开**，可以连着记几条；`Tab` 轮换落点清单，`Esc` 收起；
- 收起时未提交的内容留在内存里，下次按 C 还在 —— 不弹「是否保存」这种打断人的对话框；
- 中文输入法激活时回车只上屏，不会被当成提交（否则「写周报」三个字会存成三条半截任务）；
- 落点优先级：当前聚焦的浮窗 → 主窗口当前分组 → 上次添加过的清单 → 其余分组；
- 专注进行中记下的杂念会落款 `capture_during_focus = 1`（番茄钟的「杂念暂存」，事后能看出专注时最容易想起什么）；
- 全程**不唤起主窗口**：一旦切窗口，「不打断上下文」就不成立了。

## 六、外观

- **主题**：浅色 / 深色，跟着系统切换或手动切换（`settings.theme`）；
  切换时同步 `nativeTheme.themeSource`，菜单、对话框等原生控件一起变色。
- 分组 / 标签 / 笔记目录都支持自定义颜色，颜色贯穿侧边栏、列表与统计图表。
