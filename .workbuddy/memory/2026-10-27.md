## 笔记 Markdown：代码块着色 + Mermaid
- `renderer/js/markdown-lib.js` 整体接管 `renderer.rules.fence`：
  - ```mermaid → `<div class="md-mermaid"><pre class="md-mermaid-src">源码</pre></div>` 占位，
    再由 `enhanceMarkdown(root)` 异步渲染成 SVG；语法错误时就地显示「提示 + 源码」。
  - 其它代码块 → `highlightHook()`（highlight.js）着色，外包一层 `.md-code`
    （含语言标签 + 复制按钮，点击走 **document 级委托**，CSP 不允许内联 onclick）。
- 新增 vendor 构建：`scripts/vendor/highlight-global.mjs`（core + 38 语言，IIFE 挂
  `globalThis.hljs`，由 index.html 的 `<script>` 同步加载）+ `scripts/vendor/mermaid.mjs`
  （ESM，渲染层 `import()` 懒加载）。已在 `scripts/build-tools.js` 登记两个新 target，
  产物随仓库提交（renderer/vendor/highlight/highlight.min.js ≈163KB、renderer/vendor/mermaid/mermaid.mjs ≈5.1MB）。
- 坑（**已修，属历史 bug**）：`styledTextPlugin` 里原来把外层 `state.tokens` 直接传给
  `md.inline.parse()` 当输出数组，内层 parse 结束会跑一遍内联后处理（text_collapse 合并相邻
  text），把外层已生成的 token 合并掉 → 外层 delimiters 记录的下标失效 →
  「`==高亮==` 与 `**加粗**` 同时出现」时整段渲染抛
  `TypeError: Cannot set properties of undefined (setting 'type')`。
  改法：先解析进临时数组 `innerTokens`，再逐个 push 进 `state.tokens`。
- mermaid 主题在 `initialize` 时定死 → 监听 document 上的 `app:theme-changed`
  （由 ui.js 的 `applyTheme()` 派发）重画已渲染的图；隐藏容器里量不到宽度，
  `enhanceMarkdown` 只处理 `getClientRects().length > 0` 的块（编辑态切回预览时补画）。
