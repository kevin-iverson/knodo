# 常见问题

按「用起来觉得不对劲」的真实场景整理。每条都给了原因和做法。

> 相关文档：[开发指南](开发指南.md) · [打包与发布](打包与发布.md) · [数据库设计](数据库设计.md)

---

## 数据在哪？怎么换电脑？

默认在 `%APPDATA%\todo-desktop\`（便携版在 exe 同级 `data\`），核心是 `todo.db` 与 `attachments/`。

- 换电脑最稳的方式：侧边栏「数据 → 导出数据」得到 JSON，在新机器上「导入数据」。
- 想连附件一起搬：整个数据目录拷走（或用「File → 存储位置」把目录指到移动硬盘）。
- **录音不随 JSON 备份**：会议记录里存的是绝对路径，需要单独保留 `recordings/` 目录。

---

## 点了窗口的「关闭」，程序没退出？

这是设计如此：关闭按钮默认**最小化到托盘**。真正退出用托盘菜单「退出」。

---

## 「今天」列表里已完成的任务为什么不消失？

故意的 —— 勾完就消失会让人怀疑自己点错了。已完成的会打勾、置灰、加删除线，
列表上方显示「今日已完成 N 个任务」。

- 标记按**自然日**记录，跨天自动作废；
- 点「隐藏已完成」可以立即移除；
- 切标签页、重启应用都还在。

---

## 删掉一个已完成任务，统计数字变小了？

是的。删除会同时移除它的完成记录与统计；只是**归档**则保留统计（`completed_at` 仍在）。
要留痕就归档，别删。

---

## 计划日期为什么没有时分秒？

计划开始 / 完成日期只保留**年月日**（这是刻意的：日程粒度到天，排序和筛选都简单）；
**提醒**精确到分钟。实际完成时间记录到秒。

---

## 没配 AI Key，哪些功能不能用了？

大部分功能照常，只有三处会降级、不会报错：

| 功能 | 无 Key 时的表现 |
|---|---|
| AI 报告 | 生成本地模板报告（完成情况 / 进行中 / 逾期 / 小结），界面明确标注；自定义要求不生效 |
| AI 检索 | 只做本地分层召回，不生成总结；命中依据照常展示 |
| 知识库问答 | 降级为纯关键词召回，不生成答案 |
| 会议纪要 | 转写需要**语音** Key；纪要需要对话 Key，缺一个就少一步 |

---

## 导入数据会覆盖我现有的东西吗？

会，而且是**整块覆盖**：分组 / 标签 / 任务 / 会议 / 报告 / 检索历史 / 问答历史 / 笔记，
导入时先清空再写入。主题与 AI 配置（`settings`）保留不动。

导入前想留一手，先「导出数据」存一份 JSON。

---

## 备份里有我的 API Key 吗？

没有。导出时会排除 `ai.apiKey*`；Key 本身在本地用系统级加密（Windows DPAPI）存储，
既不明文落盘，也不下发给渲染进程。

---

## 便携版为什么没有「开机自启动」？

便携版没有稳定的安装路径，登记启动项会在下次插到别的盘时失效，所以菜单项置灰。
安装版正常可用。

---

## 把数据目录指到 U 盘 / 移动硬盘，拔掉后会怎样？

启动时会探测目录可写性，**不可用就自动回退默认目录并弹窗说明原因**，应用不会因此白屏。
重新插上硬盘后，在「File → 存储位置」里指回去即可。

另外：目标目录里已经存在 `todo.db` 时，迁移会被拒绝（避免覆盖别人的数据），换个空目录。

---

## 录制会议时能最小化到托盘吗？

**不要**。系统会把画面 / 采集轨挂起（仅音频模式不受影响）。录制时把窗口切到后台没问题。

---

## macOS 上录不到系统声音？

macOS 需要第三方虚拟声卡（BlackHole 等），本应用的采集链路以 Windows（WASAPI 回环）为准。

---

## 笔记搜索两个字的词搜不到？

不会搜不到，但走的是另一条路：全文索引用 trigram，**要求 ≥ 3 个字符**；
更短的词自动回退到 `LIKE` 模糊匹配，结果略少但不会空。

---

## 安装包为什么有 116MB？代码不是只有几 MB 吗？

体积来自 Electron 运行时（Chromium + Node），项目代码约 6MB。
这也是为什么前端库一律放 `devDependencies` 并在构建期打成一个 vendor 目录 ——
一旦有库进了 `dependencies`，`asar` 会多打包整棵 `node_modules`，体积能翻好几倍。

---

## 命令行启动 Electron 直接退出 / 打包「一闪而过」

环境里有 `ELECTRON_RUN_AS_NODE=1`（部分 IDE / Agent 宿主会设置它），Electron 会以纯 Node 模式运行。
清掉再启动：

```bash
env -u ELECTRON_RUN_AS_NODE npm start
# PowerShell
$env:ELECTRON_RUN_AS_NODE=$null; npm start
```

双击 exe 启动不受影响。

---

## 打包出来的 exe 为什么不能跑冒烟测试？

产物是打包后的单文件，不接受业务命令行参数。要验证产物，用开发版 electron 加载
`dist/win-unpacked/resources/app.asar`，或用 `scripts/check-packaged.js` 连调试端口自检
（见 [打包与发布 · 打包后自检](打包与发布.md#三打包后自检)）。

---

## 笔记里的图片存哪了？会不会把正文撑大？

图片落盘到 `<数据目录>/attachments/note-<笔记id>/`，正文里只有
`todo-media:///...` 这样的本地链接，**不塞 base64**，所以正文始终是纯文本大小。
删除笔记时对应目录会一起清理。
