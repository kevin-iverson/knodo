## 第 3 步 · 正文（整块复制，约 620 字）

```
周五下午五点，领导在群里问「这周做了什么」。

我打开待办 App，本周的任务一条不剩——勾完就被折叠了。我只能靠翻聊天记录和邮箱，把一周重新拼回来。

那天晚上我决定自己写一个。

现在它长这样（图 2 到图 6 都是真实界面，没有画原型）：

1️⃣ 勾完的任务不消失。
勾选后置灰、加删除线，但还留在列表原地；上面会写「今日已完成 1 个任务，已保留在列表中」。跨天自动归档到「已完成」，不会凭空蒸发。

2️⃣ 周五不用再回忆这周干了什么。
日报 / 周报 / 月报直接用本地完成记录生成，按 Word 版式排好，能直接改、自动保存，导出 Word 或 Markdown。还能追加一句「按计划完成时间排下个月的计划」，它就顺着这句往下写。

3️⃣ 开完会，纪要和待办已经在任务列表里。
录制时麦克风和系统声一起收（Windows 上不用装虚拟声卡），转写完自动出「议题 / 决议 / 待办 / 风险」，勾选行动项就能批量写进任务列表，还能指定挂到哪个分组。

另外两件我特别在意的事：

笔记不该是另一个 App。一条任务能关联多篇笔记，笔记也能看到自己被哪些任务引用；写在任务里的话，同样能被检索、被 AI 引用，不用在待办和文档之间来回搬。

数据是你的。本地 SQLite，没有账号、不联网同步，一个 .db 文件拷走就是全部家当。公司电脑也能用，关窗只最小化到托盘。

关于 AI 说句实话：不填 API Key 也能用全部功能，报告和检索会降级成本地方案；配了 Key 才多出总结、语义重排和问答。不是「先付费才能开始」。

只支持 Windows 10 / 11，免费开源（MIT），软件叫 Knodo，安装版和便携版都有。

如果你也在被「周五回忆一周」这件事折磨，或者你们公司对周报有特别的要求，评论区聊聊——我挺想知道别人的版本长什么样。
```

> ⚠️ **这段是违规后替换版**。原句「想要的评论区扣「1」，我把下载方式发你」已被判「以免费福利换取互动」，**永久禁用**。

## 第 6.5 步 · 私信只回「主动来问」的人

**不要在笔记或评论里承诺「私信发你」，这是诱导互动的核心句式。**
只有对方自己问「在哪下载 / 叫什么名字」时，才回复，而且分两级：

**一级（最稳，默认用这个）——只给名字，不给路径：**

```
叫 Knodo，Windows 10/11 的桌面软件，自己搜一下就能找到。
用着有问题可以回来说。
```

**二级（对方明确说搜不到时才用，有站外导流风险，自己权衡）：**

```
搜 Knodo 或者 todo-task（作者 kiverson）。
下最上面那个发行版；要随身带就下便携版，分两个卷，两个都要下齐，只解压 .001。
```

> 私信里**仍不要发链接**：小红书私信对链接、平台名很敏感，容易被吞甚至计入导流。宁可让对方多搜一次，也别为了省事把账号搭进去。
> 也**不要设置「关键词自动回复」**去发资源——那等于把违规写进自动化。
