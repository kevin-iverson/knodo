## 第二轮修复（分组/标签新增、日历空白、抽屉拖拽调宽、子任务闪烁）

### 根因
1. **分组/标签新增"点了没反应"**：`preload` 用裸 `ipcRenderer.invoke`，主进程 handler 抛错（最典型是

   try/catch，异常被吞，界面毫无反馈。用户库（%APPDATA%/todo-desktop/todo.db）里确实一条新建分组/标签都没有。
   另：`window.prompt` 在 Electron 部分版本直接返回 null，也会表现成"没反应"。
2. **日历一大块空白**：空格子是 `<span class="cal-cell empty">`，行内元素 `height:30px` 被忽略，grid 首行

3. **子任务闪烁**：每次添加/勾选都 `renderDetail()` 整页重绘，且多个异步 render 并发会互相覆盖。
4. **详情栏宽度**：原本固定 420px。

## 第四轮：日期浮层 / 拖拽排序 / Word 导出 + 分组多选 / 工具栏中文化

### 1) 子任务日期选择框被遮挡（根因）
- `.date-range-pop` 原为 `position:absolute` 且留在 `.date-range-field` 内部；祖先 `.detail-body{overflow-y:auto}`
  会让 `overflow-x` 计算成 auto → 弹层被**双向裁剪**；子任务行又是 flex 窄容器，272px 的面板必然溢出。
- 修法（`renderer/js/controls.js`）：打开时把弹层移到 `document.body` 下新建的 `.date-range-layer`
  （`position:fixed; inset:0; z-index:180; pointer-events:none`）并加 `.is-floating`（fixed + `pointer-events:auto`
  + `max-height:calc(100vh - 16px)`）；`positionPop()` 按触发器 rect 定位，右侧/下方空间不足就左移或上翻，
  始终收敛在视口内；关闭时收回控件内，保证 DOM 结构不变。
- 连带改动：`openPops` 的值从 `close` 改成 `{ close, field, reposition }`——弹层移到 body 后
  `pop.closest('.date-range-field')` 恒为 null，外部点击判定会失效。`sweepDetachedPops()` 同时检查
  field 是否还在文档里。scroll/resize 时重新定位（capture 阶段监听 scroll）。
- ⚠️ 影响面：弹层打开后**不在容器内**，任何 `container.querySelector('.cal-cell')` / `.date-range-pop`
  的查询都会失效（冒烟测试里因此挂了一次）。应用代码只读 `.dr-*-input`（留在控件内），故无影响。
- 配套样式：`.date-range-field{flex-shrink:0}`、`.dr-text` 加省略号、`.subtask-item{flex-wrap:wrap}`。

### 2) 拖拽排序无效（两个根因）
- (a) 整行 `draggable="true"` 时，行内 input/select/button 会抢走 mousedown → 多数时候根本拖不起来
  （子任务行几乎整行是 `<input class="subtask-title-input">，必现`）。
- (b) 更致命：列表顺序由 SQL 的 `completed → plan_end → priority DESC → sort_order` 决定，`sort_order`
  只是很靠后的兜底键，拖完写进去又被别的键排回去 → 看起来"拖了没反应"。
- 修法：
  - 行首加 `<span class="drag-handle">⠿</span>`，默认 `draggable="false"`，只在手柄 `pointerdown` 时置 true，
    `pointerup`/`dragend` 复位；主列表子任务行不渲染手柄。
  - 新增排序方式下拉 `#sort-select`（智能/优先级/截止日期/**手动**）；`state.sortMode`（store.js）
    非 smart 时写进 `buildFilter().sort`。
  - `main/db.js`：`f.sort==='manual'` → `ORDER BY t.sort_order ASC, t.completed ASC, (plan_end IS NULL) ASC,
    plan_end ASC, priority DESC, id ASC`。sort_order 一旦被拖拽写入就是 0..n-1 互不相同 → 顺序完全由拖拽决定；
    从未拖拽时全为 0 → 退化成原智能排序，不会突然打乱列表。
  - `ui.js: dropReorder()` 只取 `:scope > .task-item:not(.is-subtask)` 计算 ids，拖完自动切 manual + toast。
  - `compareTasks()` 在 manual 模式下改按 sort_order → id（前端树内子节点与主列表一致）。
  - `db.listSubtasks` 排序改为 **sort_order 优先**（同一父任务下拖拽是唯一排序手段，必须立刻生效）。

### 3) Word 导出 + 分组多选
- 新增 `main/docx.js`（零依赖）：手写极简 ZIP 写入器（deflate + CRC32 + 中央目录）打包 OOXML；

- 分组多选：`renderer/js/reports.js` 用自绘面板（`.multi-select` / `.ms-panel`，fixed 定位避开 `.view` 的
  overflow）替换原生 `<select>`；"全部分组"与具体分组互斥；参数改为 `groupIds` 数组（空数组=全部）。

## 第五轮：日期范围控件改用第三方 flatpickr（替换手写日历）

### 背景 / 用户诉求
- 用户反馈「添加任务时选日期范围出现**两次弹出**」，只应弹一次并要求自动回填；并明确建议
  **不要自己写控件，改用第三方依赖**。（我这边看不到用户发的截图，只能按文字描述 + 代码定位。）

### 实现
- `renderer/vendor/flatpickr/`：把 `node_modules/flatpickr/dist/flatpickr.min.js`、
  `flatpickr.min.css`、`l10n/zh.js`（改名 `l10n-zh.js`）**随项目落地**，不依赖 node_modules 路径。
  `package.json` 增加依赖 `flatpickr@^4.6.13`。
- `renderer/index.html`：先引 vendor CSS 再引本项目 CSS（否则 vendor 优先级更高，主题覆盖失效）；
  两个经典 `<script>` 放在 `<script type="module">` 之前（module 默认 defer，`window.flatpickr` 必定就绪）。
- `renderer/js/controls.js`：**删掉全部手写日历**（`.date-range-pop` / `.cal-grid` / `positionPop()` 等），
  改为薄封装：`.date-range-field` 内除两个隐藏 input 外多一个 `<input class="dr-input">` 作为 flatpickr 锚点
  （`position:absolute; inset:0; opacity:0; pointer-events:none`，只提供定位矩形）。
  对外 API 完全不变（`dateRangeFieldHtml / bindDateRangeFields / getDateRange / validateDateRange /
  DATE_RANGE_EVENT`），所以 `ui.js` / `detail.js` 的调用点一行都不用改。
- 配置要点：
  - `mode:'range'`：两次点选成范围；`closeOnSelect` 默认 true，选满 2 个日期**自动关闭**并回填（正是需求）。
  - `clickOpens:false` —— **这是"弹两次"的关键**：否则 focus 与 click 各开一次。
  - `ignoredFocusElements:[trigger]` —— flatpickr 的 document mousedown 会把触发器当"点击外部"先关，
    随后 click 又开 → 触发器永远关不掉；加上这条才能正常 toggle。
  - `position: fn`：flatpickr 自带 auto 只在"上方也放得下"时才上翻，抽屉底部的子任务行仍会掉出屏幕；
    自己实现 `positionRangeCalendar()`（下方优先 → 上翻 → 收敛进视口 8px 边距）。
  - `animate:false` 避免呼出时"跳一下"；`locale:{...zh, firstDayOfWeek:1}`（官方 zh 包没设首日）。
  - `onReady` 里往 `calendarContainer` 追加快捷条（今天/明天/本周末/清除），保留旧版行为。
  - `boundRanges` Set + `sweepDetachedRanges()`：宿主 DOM 被重渲染移除后 destroy，避免 body 留孤儿面板。
  - 新增导出 `isAnyRangeOpen()`：`detail.js` 的 Esc 关抽屉用它让路（否则一次 Esc 同时关面板 + 抽屉）。
    顺手把 `detail.js` 里 `addEventListener(..., {once:true})` 的 Esc 监听改成模块级单例 `ensureEscHandler()`
    （原写法被吃掉一次后就再也不会触发）。
- `renderer/css/styles.css`：删掉全部 `.cal-*` / `.date-range-pop` / `.date-range-layer` 样式；
  改为 flatpickr 主题覆盖（全部用 CSS 变量 → 浅/深色自动跟随）+ `.dr-input` + `.dr-fp-foot` 快捷条样式。

### 踩坑记录（务必记住）
- `main/main.js` 的冒烟脚本是模板字符串，注入的 JS 里**不能出现反引号**（会提前结束模板 → SyntaxError）。
- 断言选择器要从 `.cal-cell[data-date]` 换成 `.flatpickr-day`；flatpickr 的日期元素带 `.dateObj` 属性，
  直接读 `el.dateObj` 比解析 aria-label 稳。
- flatpickr 没有"空格子"（用 prevMonthDay/nextMonthDay 补位），原先那条"空 cell 高度"回归断言已无意义，
  换成「面板必须完整落在视口内 / 父节点必须是 body / 不在裁剪容器内」。
