## 实用工具「巨大图标」修复（用户报障）
- 现象：代码格式化 / JSON 查看器 / 文本对比浮窗里出现巨大蓝底白勾图标。
- 根因：**CSS 类名冲突**——「语法高亮」复选框用了 `fmt-hl` / `jv-hl`（与高亮层 `<pre>` 同名），
  该类是 `position:absolute; inset:0; pointer-events:none`，checkbox 被拉伸成整个浮窗大小的
  原生控件，勾选态就是巨型蓝块。`.df-hl` 无样式但顺手一起改了。
- 修复：复选框类名改为 `fmt-hl-toggle` / `jv-hl-toggle` / `df-hl-toggle`
  （code-format.js / json-view.js / text-diff.js），冒烟脚本 main.js 里的 `.df-hl` 选择器同步更新。
- 排查方法：CDP `elementsFromPoint` 没找到（pointer-events:none 不参与命中），
  要按 `getBoundingClientRect` 几何扫全元素才逮到。
- 期间误判过「图片放大预览层」：img-zoom 关闭逻辑正常（点遮罩/Esc/双击均可关）。
