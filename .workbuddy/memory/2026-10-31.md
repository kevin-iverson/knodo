## 任务视图「笔记弹窗」（不离开任务就能看/改笔记）

- 入口：`renderer/index.html` 顶栏搜索框内右侧 `#btn-notes-dock`（`.search-action`，📝 图标）。
  **为什么是搜索框内附件而不是并排按钮**：1080 窗口下 `.topbar-right` 可用 790px，原有内容已占 788px，
  任何新按钮都会把「＋ 新建任务」挤到第二行；放在框内（`padding-right:36px` + 绝对定位）不改行宽。
- 实现：`notes.js` 新增 `openNotesDock()`，复用 `renderNotes()` / `bindEvents()` / 右栏逻辑，
  只把宿主从 `#view` 换成弹窗里的 `#nt-dock`（`boundRoot` 本就是「当前活着的笔记宿主」语义）。
  关窗时 `boundRoot = null`（容器已移除），`activeNoteId` 保留 → 再次打开回到上一篇。
  `renderNotes()` 开头加守卫：弹窗开着时 `#view` 不抢宿主（编辑器/saver 是单例，两份骨架会互踩）。
- `modal.js` 的 `openPanelModal` 新增 `escGuard(mask)`：返回 true 时这次 Esc 让给内部（笔记搜索框先清空关键词）。
- CSS：`.modal.modal-notes-dock`（1320×900 上限，三栏各自滚动，替换原 100vh 限高）；
  `@media (max-height:660px)` 给 `.nt-dp-scroll` 最小 200px + 面板整块滚动，
  否则矮窗口下正文被压成 0 高、底部按钮被裁。
- 验证：CDP 断言（开关窗、列表/详情、分栏编辑器、Esc 守卫、最大化、回收站、删除、关窗兜底保存、
  弹窗开着时视图不抢宿主）+ `npm run smoke` SMOKE_OK。脚本在 `D:/WorkBuddyWorkSpace/.tmp/check-dock*.js`。
